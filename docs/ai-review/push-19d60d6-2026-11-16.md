### 2. 使用了 `ref` 但未导入
- **严重程度**：严重（会导致运行时报错）
- **位置**：`const count = ref()`
- **原因**：`<script setup>` 中 `ref` 不会自动注入，必须显式 `import { ref } from 'vue'`，否则运行时报 `ref is not defined`。
- **修改建议**：
  ```js
  import { ref } from 'vue'
  const count = ref()
  ```
